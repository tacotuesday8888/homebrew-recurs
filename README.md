# Homebrew Recurs

Official Homebrew tap for [Recurs](https://github.com/tacotuesday8888/recurs),
the coding-agent harness for user-governed, bounded agent teams.

```bash
brew install tacotuesday8888/recurs/recurs
```

The formula installs the exact public npm archive and keeps Node.js as the
runtime. On Linux it also installs Bubblewrap for subprocess containment.

Formula updates are copied from an attested Recurs release asset and must pass
an install-and-run check before merge.
